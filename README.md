# Verification data for the CPS–DDM precipitation study

Added value of dynamical downscaling and calibration for subseasonal summer rainfall over the middle and lower Yangtze River region

The CSVs contain derived verification results for the 15 initialization years from 2008 to 2022. Forecast windows such as D16-D45 use inclusive lead-day bounds. The manuscript and Supporting Information define the metrics, comparison families and resampling procedures.

## Annual scores and geometry

| File | Contents |
|---|---|
| [full_annual.csv](Verification_Data/full_annual.csv) | Annual spatial verification for the cumulative windows. |
| [full_regional_annual.csv](Verification_Data/full_regional_annual.csv) | Annual area-weighted regional amounts and errors. |
| [full_summary.csv](Verification_Data/full_summary.csv) | Window summaries including spatial and regional RMSE and RMSE skill scores. |
| [full_geometry_annual.csv](Verification_Data/full_geometry_annual.csv) | Annual rainfall-centre and high-value-area diagnostics. |
